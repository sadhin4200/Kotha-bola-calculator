# Talking Calculator (কথা বলা ক্যালকুলেটর)

A kids' calculator that speaks numbers and answers aloud in Bangla and English, with practice, lessons, stories and number-memory pages.

Single static page, no build step, no dependencies.

## Files

- `index.html` the whole app
- `logo.svg` logo and browser icon

## Publish with GitHub Pages

1. Create a new repository and upload `index.html` and `logo.svg` to the top level.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. After a minute the app is live at `https://<your-username>.github.io/<repo-name>/`.

## Notes

- Speech uses the browser's built-in voices, so the Bangla voice depends on the device.
- The page uses system fonts only, so nothing extra has to download.
